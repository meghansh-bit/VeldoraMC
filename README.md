# VeldoraMC

VeldoraMC Minecraft server website.

## Setup
The website source will be extracted into the repository root from `VeldoraMC-Bundles-Payments.zip`.

After extraction, import this GitHub repository into Vercel and use:
- Build command: `npm run build`
- Output directory: `dist`

Do not commit secrets, `.env` files, payment credentials, or Minecraft server credentials.
